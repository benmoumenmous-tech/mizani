ميزانيتي – ملفات الرفع

ارفع الملفات الأربعة الموجودة في هذا المجلد إلى جذر مستودع mizani على GitHub: index.html و manifest.webmanifest و sw.js و README.md.

البيانات محفوظة محليا على الجهاز. لا ترفع نسخك الاحتياطية إلى GitHub. رمز PIN قفل واجهة إضافي وليس تشفيرا للبيانات. مسح بيانات المتصفح قد يؤدي إلى فقدان البيانات والرمز. صدّر نسخة احتياطية بانتظام.
